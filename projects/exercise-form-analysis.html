sEMG + Movement Feedback

Exercise-Form Analysis

An exploratory instrumentation project translating muscle-activation features into movement-quality feedback across five labeled exercise conditions.

Roles

sEMG acquisition, CSV logging, signal processing, feature extraction, classification logic

Collaboration

Instrumentation final project with Essie Fisher

Tools

MyoWare, Elegoo Uno R3, Arduino serial, Python, CSV, moving-average smoothing

Conditions

Good form, weak contraction, jerky motion, partial extension, fast motion

Project Overview

This project explored whether muscle-activation patterns could support feedback about exercise consistency and movement quality. The system recorded labeled sEMG trials, processed short windows in Python, extracted descriptive features, and returned a form label or an uncertain result when the closest profiles were too similar.

Acquisition & Analysis

  1. Capture muscle activity with a MyoWare sensor and surface electrodes.
  2. Verify serial readings through the Uno-compatible microcontroller.
  3. Log labeled trials to CSV for repeatable analysis.
  4. Apply windowing and moving-average smoothing in Python.
  5. Extract RMS, variance, and peak-count features.
  6. Compare features with class reference profiles using standardized distance.
  7. Return a form label or an uncertain result when the comparison is too close.

Project Scope

This was an exploratory laboratory prototype. It demonstrated the complete acquisition-to-feedback workflow, but independent classification accuracy and generalization across users have not been established.

Future Improvements

  • Collect repeated trials across more participants and sessions.
  • Standardize electrode placement and contraction protocols.
  • Evaluate the classifier with a held-out test set.
  • Compare the distance-based approach with supervised machine learning models.
